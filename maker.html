3. Preview & download

How to publish a new test

  1. Click Download test file. You get a file like practice-1.js.
  2. On GitHub, open your repository → folder tests → Add file → Upload files → upload it → Commit changes.
  3. Open config.js on GitHub (pencil icon ✏️) and add the line shown below to the tests list. Commit.
  4. Wait about 1 minute, then reload the student page. The new test appears.
  5. Keep the .txt and the answer key on your own computer. Do not upload the answer key to GitHub.
